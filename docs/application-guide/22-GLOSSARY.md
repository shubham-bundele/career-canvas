# Glossary

> CareerCanvas Application Guide | Generated: 2026-08-12

---

| Term | Definition |
|------|-----------|
| **ATS** | Applicant Tracking System — software used by employers to screen resumes |
| **ATS Mode** | Editor mode that enforces ATS-safe formatting (safe fonts, single column, no photo) |
| **Achievement** | A bullet point describing a work accomplishment, typically with metrics |
| **Autosave** | Automatic document saving after 1 second of inactivity |
| **CDN** | Content Delivery Network — external hosting for third-party libraries |
| **CareerCanvas** | The application name; a local-first career document toolkit |
| **Cover Letter** | A document type for job application letters |
| **CV** | Curriculum Vitae — a comprehensive career document, typically longer than a resume |
| **Design Panel** | Editor component with 8 groups of design controls (typography, colors, spacing, etc.) |
| **Design Preset** | A saved combination of design settings (font, colors, spacing) |
| **Design Studio** | The slide-in drawer in the editor containing design controls |
| **Document** | A career document (resume, CV, cover letter, reference sheet) stored in IndexedDB |
| **Entry** | A single item within a section (e.g., one job in Experience, one degree in Education) |
| **EventBus** | Global publish-subscribe event system for inter-module communication |
| **Font Manager** | Editor component for selecting fonts, sizes, and line height |
| **Groq** | AI inference platform providing the Llama model used for AI analysis |
| **Guest Mode** | Default operating mode with no account required; all data stored locally |
| **Hash Router** | Client-side routing via URL hash (`#/path`); no server configuration needed |
| **IDB** | IndexedDB — browser-side database for storing documents and application data |
| **Import Manager** | Module handling file import from JSON, DOCX, PDF, and plain text |
| **Job Matcher** | Career tool that compares resume keywords against a job description |
| **LinkedIn Draft** | A document type for drafting LinkedIn profile content |
| **localStorage** | Browser storage for preferences, settings, and small configuration data |
| **Mammoth.js** | Library for converting DOCX files to HTML (loaded from CDN) |
| **Master Profile** | A unified professional profile that can inform multiple documents |
| **OCR** | Optical Character Recognition — extracting text from scanned PDF images |
| **Onboarding Wizard** | Multi-step document creation flow with type-specific options |
| **PDF.js** | Mozilla library for rendering and extracting text from PDF files (loaded from CDN) |
| **PDF Studio** | Standalone PDF viewer tool (not related to resume PDF export) |
| **PKCE** | Proof Key for Code Exchange — OAuth security enhancement used by Supabase |
| **Reference Sheet** | A document type listing professional references |
| **Resume** | A concise career document, typically 1-2 pages |
| **Rich Text** | Formatted text with bold, italic, underline, lists, and links |
| **Section** | A named group of content in a document (e.g., Experience, Education, Skills) |
| **Section Navigator** | Editor panel showing all sections with search and filter |
| **Skills Matrix** | Career tool analyzing skill evidence strength across resume content |
| **Smart Formatter** | Rule-based document analyzer with 100-point scoring |
| **Snapshot** | A versioned copy of a document saved in the Version Studio |
| **StateManager** | Centralized observable state store with undo/redo and snapshots |
| **Supabase** | Backend-as-a-Service used for optional authentication |
| **Template** | A rendering function that converts document data into styled HTML |
| **TemplateEngine** | Registry and renderer for document templates |
| **Tesseract.js** | OCR library for extracting text from images (loaded from CDN) |
| **Theme** | Application UI appearance (backgrounds, text colors, borders) |
| **ThemeEngine** | Manager for applying and switching application UI themes |
| **Theme Studio** | Full-page tool for browsing, creating, and customizing app themes |
| **Toast** | Brief notification message shown in the corner (or bottom on mobile) |
| **Typography Preset** | A named combination of font, sizes, and colors for document design |
| **Vercel** | Deployment platform for hosting static files and serverless API routes |
